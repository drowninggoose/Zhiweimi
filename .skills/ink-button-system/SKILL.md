# 墨印按钮系统

## 形制

| 类型 | 形制 | 用在哪 | 形状 |
| --- | --- | --- | --- |
| 主行动 | 印章 | 开始烹饪、保存、生成计划 | 近方、四角不等、内圈虚线、下沉墨影 |
| 次行动 | 笺纸 | 取消、查看、换一批、我的收藏 | 纸白、虚线边、左上角小孔 |
| 筛选 | 竹简 | 餐次 / 时间 / 品类 / 菜系 | 窄长、上下切角、选中反白为墨色 |
| 轻行动 | 墨字 | 清除筛选、查看全部 | 无底、波浪下划线、字距略松 |

## 形状参数

不要全站 `border-radius: 999px`。使用不等圆角制造“手工裁纸”的感觉：

```css
/* 印章 */
border-radius: 7px 15px 9px 13px / 13px 9px 15px 7px;
/* 笺纸 */
border-radius: 5px 13px 7px 11px;
/* 竹简 */
border-radius: 4px 10px 4px 10px;
```

主行动按钮内部加一层 `inset 4px` 的虚线，像印面边框；次行动用左侧一个小孔或一条装订线。

## 状态

- hover：上移 2px，阴影变深，允许 `rotate(-0.6deg)`。
- active：下压 1px，阴影缩到 1px。
- focus-visible：2px 虚线外圈，不能因为 `overflow: hidden` 被裁掉。
- disabled：只降透明度，不改变形制。
- 触控热区不小于 44×44；小字号按钮用 padding 补足。

## 图标化

| 动作 | 图标 | 形态 |
| --- | --- | --- |
| 收藏 / 取消收藏 | 心形（实心 / 空心） | 圆形小印，选中转朱砂 |
| 开始烹饪 | 火焰 | 火焰 + 两字短词“开火”，不再写“开始烹饪” |
| 编辑 / 创建副本 | 铅笔 / 双页 | 圆形小印 |
| 删除 | 垃圾桶 | 圆形小印，禁用色保留朱砂描边 |
| 上移 | 向上箭头 | 圆形小印 |
| 搜索 | 放大镜 | 单枚圆印 |

图标按钮必须有 `aria-label`；鼠标用户靠 `title` 补足含义。同一行最多一个图标 + 一个带字按钮。

## 禁止

- 同一行出现三种以上形状。
- 为了造型把文字挤出按钮。
- 用 `clip-path` 裁掉焦点环或省略号。
- 主按钮和次按钮只靠颜色区分，形状完全一样。
