## 这次针对三个问题的处理

### 1. GIF 重影

- 原因：GIF 每帧用了 `disposal=1`（保留上一帧），但帧本身带透明区域，浏览器会把上一帧透出来，形成多重轮廓。
- 修复：重新生成全部 12 个 GIF，改为 `disposal=2`（每帧先清回透明背景再绘制），并保留透明索引 0，避免黑闪。
- 页面引用统一升级到 `?v=3`，避免浏览器继续使用旧缓存。

### 2. 不再每页放一张小卡

- 删除了原先固定在每页右侧的“小卡 + 竖排文案 + GIF 展台”。
- 首页：保留 hero 内的形象，不再额外叠加。
- 内容密集页（菜谱库、烹饪、设置等）：不强行放插画。
- 真正空着的页面（饮食计划、厨具、食材、空搜索结果等）：在空状态卡片右侧放一只合适大小的 GIF，即“原有留白处补形象”。
- 首页内容恢复全宽，不再为插画列让位。

### 3. 封面与“拆信”过渡

- 去掉了独立的“点击进入”按钮；整张封面本身就是按钮，点击页面任意位置都进入主页。
- 右下角不再放印章纸签，只在页脚保留一行小提示“轻点任意处 · 拆开信封”。
- 封面底部保留信封口袋的折线轮廓。
- 点击后：信纸从口袋中向上抽出，覆盖封面，纸面出现“知味咪”暗纹与火漆印，随后进入主页。

## 网页实现

- 启动：`npm run dev`（Vite 默认 5173，被占用时会自动换端口）
- 构建：`npm run build`
- 单测：`npm test`
  - 83 / 84 通过；唯一失败是原有《日记心得保存后再次打开》用例（与本次 UI 改动无关，未改 Diary 数据逻辑）。
- 新增封面测试：`src/test/portal.test.tsx`。

## 设计说明

- 主色保持原来的纸白、奶油杏、朱砂、深咖，没有换主题。
- 标题用楷体/手写感，正文用无衬线，保持“家庭食谱本”的气质。
- 图标的“球形助手”从 82px 猫脸球体开始，支持拖动、吸附边界、记忆位置、单击展开面板。
- 留白插画只出现在空状态，避免遮挡内容。
- 侧栏固定在左侧，AI 球固定在桌面位置：滚动页面时两者都不动；只有拖拽球体时，球体才移动到新位置，并记住这个屏幕位置。
- 滚动行为预览见 `preview-fixed.png`。
