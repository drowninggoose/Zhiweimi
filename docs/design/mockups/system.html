形状规则

不对称圆角

每个容器四角半径不同，像手画的框。半径 14–26px。

2px 描边

所有卡片都有棕色描边，不用灰阴影做层级。

纸片阴影

3–4px 硬偏移，颜色是描边棕的 13–18% 透明。

6% 纸纹

全局一层噪声，千万别再加渐变光晕。
