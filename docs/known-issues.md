# 运行边界

- 支持桌面 Chrome/Edge，不做手机适配、真实AI、云同步、账号或网站部署。
- 菜谱库为抓取自公开菜谱网站的图文数据，图片为外链、离线时无法显示；用量与火候描述按原站点保留，实际烹饪效果需要用户自行观察。
- 用户上传图片只支持 JPEG/PNG/WebP，单张原图上限 10 MB，压缩最长边 1600 px。浏览器存储配额不足会显示错误；请及时导出备份。
- 所有数据属于当前浏览器和 localhost 地址，清除站点数据后需自行导入备份。烹饪进度保存在当前浏览器本地，清除站点数据或换浏览器后无法恢复。
- 备份文件上限 100 MB；超过时需减少图片数据或分批保存记录，当前版本不支持分卷备份。
