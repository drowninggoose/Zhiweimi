## 失败定位与修复记录

1. JSDOM Blob 不能被 Node 结构化克隆：数据库 Blob 技术验证改用原生 Node Blob，内容与尺寸断言保留，随后真实 Chrome 验证上传图片。
2. 测试数据库删除后关闭：每个用例显式 open，避免跨用例生命周期错误。
3. TypeScript 配置输出模式与类型缺失：配置仅类型检查，纳入 Node 类型，构建通过。
4. React 静态规则：共享上下文/导航/Hook 分文件，Blob URL 同步到 DOM，异步数据库初始化取消过期更新；未关闭规则。
5. 导航选择器同名卡片冲突：限定导航区域，全部原验收断言保持。
6. 数据路由的 JSDOM AbortSignal 与 Node Request 类型不兼容：测试环境使用同一原生信号构造器，回归通过。
7. 首轮浏览器图片测试的 PNG 损坏：替换为带正确 CRC 的本地 PNG 测试数据；上传预览与真实图片内容断言保留。
8. 主题下拉框名称不稳定：增加明确 aria-label；持久化图片测试尺寸改为测试图片真实32像素预期。
9. 逗号分隔字段逐字输入吞掉分隔符：编辑时保留空段，保存/生成时才归一化，多偏好与清空回归通过。
10. 最近查看未同步首页：查看记录经统一操作刷新本地快照，首页立刻反映最新记录。
11. Windows 沙箱临时目录在测试进程间不一致：Vitest 模块缓存固定到工作区 node_modules/.vitest-cache，完整32项及之后34项测试通过。
12. 首次生成 Playwright 报告后 lint 扫到第三方压缩代码：仅忽略生成报告和测试输出，所有项目源代码、单元测试和端到端测试继续完整 lint。
13. Windows PowerShell 5 启动健康检查的 IE 解析与中文编码误判：使用 UseBasicParsing 并以 UTF-8 解码页面；复用服务和全新启动两条路径均实际执行成功。失败启动会结束本次启动的服务进程。
